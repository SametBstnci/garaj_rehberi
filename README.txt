GARAJ REHBERİ - BAŞLANGIÇ DOSYALARI

Dosyalar:
- index.html: ana sayfa
- styles.css: tasarım
- script.js: mobil menü
- hakkimizda.html, iletisim.html, gizlilik.html: temel sayfalar

Önizleme:
index.html dosyasına çift tıklayarak tarayıcıda açabilirsiniz.

Ücretsiz yayınlama:
1. GitHub hesabı oluşturun.
2. Yeni bir public repository açın (ör. garaj-rehberi).
3. Bu klasördeki dosyaları repository'ye yükleyin.
4. Repository > Settings > Pages bölümüne girin.
5. Deploy from a branch seçin; branch olarak main ve klasör olarak /(root) seçip kaydedin.
6. GitHub Pages'in verdiği adres üzerinden sitenizi açın.

Yayın öncesi:
- İletişim sayfasındaki örnek e-posta metnini kendi adresinizle değiştirin.
- İçerik kartlarını gerçek, özgün makalelerle değiştirin.
- Gizlilik metnini eklediğiniz analiz/reklam araçlarına göre güncelleyin.
- Fotoğraf Unsplash üzerinden uzaktan yüklenir; isterseniz lisans koşullarını kontrol edip kendi görselinizle değiştirin.
